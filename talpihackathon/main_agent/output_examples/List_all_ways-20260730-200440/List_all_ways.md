כדי למצוא את כל סעיפי התקציב הקשורים לנושא מסוים, אשתמש בשלבים הבאים:

1.  **הבנת מבנה הנתונים (`DatasetInfo`):** ראשית, אקרא את המידע על מבנה הנתונים של `budget_items_data` באמצעות הכלי `DatasetInfo`. זה יאפשר לי להבין אילו עמודות זמינות לחיפוש ומה המבנה שלהן.
2.  **חיפוש טקסט חופשי (`DatasetFullTextSearch`):** לאחר מכן, אשתמש בכלי `DatasetFullTextSearch` על מערך הנתונים `budget_items_data` עם מילות מפתח הקשורות לנושא הספציפי. חיפוש זה יחזיר לי מזהים רלוונטיים (כמו קוד תקציב, כותרת) של סעיפי תקציב התואמים את החיפוש.
3.  **שאילתת בסיס נתונים (`DatasetDBQuery`):** לבסוף, לאחר שיהיו לי מזהים רלוונטיים, אבנה שאילתת SQL באמצעות הכלי `DatasetDBQuery` כדי לאחזר מידע מפורט יותר על סעיפי התקציב שנמצאו, כולל סכומי הקצאה, ביצוע, וקישורים לפריטים (`item_url`).

לכן, הדרך העיקרית למצוא סעיפי תקציב לפי נושא ספציפי היא באמצעות חיפוש טקסט חופשי (full-text search) על נתוני סעיפי התקציב.
